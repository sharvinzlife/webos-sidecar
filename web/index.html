LG setup

How to turn Developer Mode on, clearly

1
On the TV remote, press Home and open LG Content Store.

Search exactly for Developer Mode and install that app.

2
Open the Developer Mode app and sign in.

Use your LG Developer site account, not just a normal TV profile.

3
Switch Dev Mode Status to ON.

The TV will reboot. That part is expected.

4
Open Developer Mode again after the reboot.

Now press Key Server. The app shows a 6-character passphrase at the bottom-left.

5
Come back here and add the TV connection.

Use your TV IP, port 9922, username prisoner, and leave the password empty.

6
Keep Developer Mode alive.

Watch the remaining session time and hit EXTEND before it reaches zero, or LG removes your sideloaded apps.

Quick rule

Your computer and TV must be on the same network. If Developer Mode expires, the apps you sideloaded disappear from the TV.

Paste the right link

Make the asset finder actually useful

  • Works: a direct .ipk URL, a GitHub repo, a releases page, or a GitHub org/user page.
  • Moonfin example: pasting https://github.com/Moonfin-Client scans its repos and surfaces the Smart-TV webOS release.
  • Litefin example: the dashboard understands https://github.com/MoazSalem/litefin/releases and will show the webOS .ipk variants instead of the Tizen .wgt files.
  • Best input: use the exact platform repo or releases page when you know it, like the project’s Smart-TV/webOS repo.
  • Still wrong for LG: source zips, APKs, or Samsung .wgt files.
LG reminder: install .ipk on LG webOS. If you see .wgt, that is the Samsung/Tizen package instead.

The resolver checks GitHub live and explains what it found instead of just leaving the panel blank.

Quick launch

Download it, open it, run one command

The repo is intentionally tiny: Python serves the dashboard, wraps the official LG CLI, and stores your recent packages locally. The install path is the same everywhere: grab the repo, extract it or cd into it, then run the launcher for your platform. ✨

🌐 Open GitHub ⬇️ Download ZIP 🧾 Releases
macOS 🍎 1. ⬇️ Download ZIP or clone the repo 2. 📂 Extract it, then cd webos-sidecar ./launch.sh Launch from Terminal with the Unix wrapper.
Linux 🐧 1. ⬇️ Download ZIP or clone the repo 2. 📂 Extract it, then cd webos-sidecar ./launch.sh Same path as macOS, including the Node shim and dependency checks.
Windows 🪟 1. ⬇️ Download ZIP or clone the repo 2. 📂 Extract it, then cd webos-sidecar launch.cmd Run from Command Prompt or double-click it. PowerShell also works with .\launch.ps1. 
python launch.py --check

The shared launcher creates a venv, installs Python dependencies, installs @webos-tools/cli, injects the Node compatibility shim, validates startup, and opens http://127.0.0.1:3847 automatically.
